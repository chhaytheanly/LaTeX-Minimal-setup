\section{Project Description} 
\label{sec:project_description}

This thesis presents the design, development, and deployment of ``An Accurate Fasteners Counting System on the Conveyor Belt,'' an end-to-end edge-AI framework for the real-time detection, classification, and tallying of metallic fasteners in industrial environments. The proposed solution integrates a custom object-detection architecture, \textbf{YOLO11-GED}, which features a novel \textbf{EMAc2f} module combining multi-scale attention, GhostNet-based feature reuse, and dynamic upsampling. This model is encapsulated within a full-stack desktop and web application designed for live video analytics and telemetry. Deployed locally on an NVIDIA Jetson edge device with TensorRT acceleration and an Intel RealSense camera, the system eliminates cloud dependency while actively mitigating challenges such as specular glare, occlusion, and extreme scale variations. By automating manual visual inspection, this framework delivers low-latency, continuous counting that reduces human error and streamlines manufacturing operations.

\subsection{Problem Statement}
\label{sec:problem_statement}

The imperative for an automated fastener counting system stems from a convergence of operational inefficiencies and unresolved technical challenges in contemporary industrial automation. These challenges are categorized into three primary domains:

\begin{itemize}
    \item \textbf{Operational and Industrial Challenges:}
    \begin{itemize}
        \item Manual visual counting on high-speed conveyor belts is cognitively demanding, leading to compounding human errors, inconsistent inventory records, and costly production bottlenecks.
        \item Weight-based estimation methods, frequently employed as a fallback, lack the granular precision required for modern supply-chain management and cannot differentiate between distinct component types.
        \item The absence of a reliable, continuous counting mechanism necessitates frequent manual audits, inflating labor costs and delaying logistical operations.
    \end{itemize}

    \item \textbf{Technical and Algorithmic Challenges:}
    \begin{itemize}
        \item Fasteners are small, highly reflective metallic objects that produce specular glare under factory lighting, confounding standard detection pipelines.
        \item On moving conveyors, parts frequently overlap and cluster densely, causing general-purpose detectors to merge adjacent instances or produce false negatives.
        \item Heavy, high-accuracy models (e.g., Faster R-CNN ~\cite{ren2016fasterrcnnrealtimeobject}, large Transformer-based detectors) cannot sustain the inference throughput required to match conveyor speeds.
        \item Conversely, lightweight models (e.g., base YOLO variants) often sacrifice the small-object recall necessary to reliably detect micro-components within dense clusters.
    \end{itemize}

    \item \textbf{Hardware and Deployment Constraints:}
    \begin{itemize}
        \item Cloud-based inference introduces unacceptable latency, relies on unstable network connectivity, and raises data-sovereignty concerns within secure factory environments.
        \item Edge devices, such as the NVIDIA Jetson series, offer local, low-latency processing but impose strict limits on memory footprint, Floating Point Operations (FLOPs), and power consumption.
        \item The system must deliver real-time performance ($\geq 30$ FPS) while executing entirely on embedded hardware, leaving no margin for unoptimized or computationally redundant architectures.
    \end{itemize}
\end{itemize}

\subsection{Objectives}
\label{sec:objectives}

The overarching aim of this internship was to design and deliver a high-precision, real-time vision system for automated fastener counting, while simultaneously advancing expertise in computer vision, edge computing, and full-stack system engineering. To reflect both the professional mandate and the academic rigor of the internship, the objectives are delineated into two complementary categories.

\begin{itemize}
    \item \textbf{General Objective:} \\
    To develop and validate a complete, cloud-independent counting solution capable of detecting and tallying small, reflective, and densely overlapping metallic fasteners in real time on edge hardware within an operational industrial environment.

    \item \textbf{Specific Objectives:}
    \begin{enumerate}
        \item[\textbf{A.}] \textbf{Professional and Industrial Objectives (Client Deliverables)}
        \begin{itemize}
            \item \textbf{Baseline Benchmarking:} Evaluate nine configurations across three modern detector generations (YOLOv8~\cite{yaseen2024yolov8indepthexplorationinternal}, YOLO11~\cite{khanam2024yolov11overviewkeyarchitectural}, YOLOv26~\cite{jocher2026ultralyticsyolo26unifiedrealtime} in nano, small, and medium scales) to identify the optimal accuracy-speed trade-off for the target hardware.
            \item \textbf{Domain-Specific Dataset Curation:} Collect, annotate, and augment a proprietary dataset of fastener images captured under realistic conveyor conditions, incorporating variable lighting, motion blur, specular glare, and dense overlap.
            \item \textbf{Full-Stack Platform Development:} Implement an end-to-end production system comprising a multi-threaded Python vision engine, a high-performance TypeScript/Bun REST API, a persistent relational database, and dual user interfaces (a web dashboard and a native PyQt6 desktop application).
            \item \textbf{Edge Deployment and Integration:} Deploy the pipeline (Intel RealSense $\rightarrow$ NVIDIA Jetson with TensorRT $\rightarrow$ API $\rightarrow$ UI) on a physical conveyor test bench, targeting a minimum of $\geq 30$ FPS and mAP@0.5 $\geq 0.95$ without cloud dependency.
        \end{itemize}

        \item[\textbf{B.}] \textbf{Academic and Pedagogical Objectives (Research Contributions)}
        \begin{itemize}
            \item \textbf{Efficient Architecture Design:} Develop \textbf{YOLO11-GED}, a lightweight detector centered around the novel \textbf{EMAc2f} module (integrating Efficient Multi-scale Attention, GhostNet-based feature reuse, and Dynamic Upsampling), to investigate how small-object recall can be maximized under stringent edge-compute budgets.
            \item \textbf{Rigorous Experimental Analysis:} Validate YOLO11-GED against established baselines through quantitative metrics and ablation studies, isolating the empirical contribution of each architectural modification.
            \item \textbf{Academic Dissemination:} Document the complete design-to-deployment methodology in this thesis and formally defend the findings before the academic examination jury.
        \end{itemize}
    \end{enumerate}
\end{itemize}
